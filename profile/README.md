# 📚 Codex 함께 공부하기

인프런 **「코덱스 참교육 - Codex 업무 자동화부터 바이브 코딩까지」** 강의를 함께 수강하고, 배운 내용을 기록하는 스터디입니다.

강의를 듣는 데서 끝내지 않고, 직접 실습하고 서로의 경험을 공유하는 것을 목표로 합니다.

## 🗓️ 진행 방식

1. 회차별로 정해진 강의 범위를 학습합니다.
2. 강의를 보며 직접 실습합니다.
3. 학습한 내용을 **개인별 GitHub Issue**로 작성합니다.
4. 다른 참여자의 Issue를 읽고 질문이나 피드백을 댓글로 남깁니다.

> 예: 이번 회차의 학습 범위가 섹션 1~3이라면, 각자 해당 범위를 학습한 뒤 Issue를 하나씩 작성합니다.

학습 범위와 작성 기한은 회차별 공지를 확인해 주세요.

## ✍️ 학습 기록 작성 방법

### 1. Issue 만들기

이 저장소의 **Issues → New issue**에서 새로운 Issue를 작성해 주세요.

- **한 회차당 개인별 Issue 1개**를 작성합니다.
- 같은 회차의 학습 기록은 본인의 Issue에 이어서 수정합니다.
- 기한까지 학습을 마치지 못했다면, 진행한 범위와 남은 내용을 먼저 기록해 주세요.

### 2. 제목 작성하기

아래 형식으로 제목을 작성해 주세요.

`[N회차] 이름 - 섹션 X~Y`

**예시**

`[1회차] 홍길동 - 섹션 1~3`

### 3. 본문 작성하기

아래 템플릿을 복사해서 작성해 주세요.

모든 내용을 길게 적을 필요는 없습니다. **무엇을 배웠고, 직접 무엇을 해봤는지**가 드러나면 충분합니다.

```markdown
## 📌 학습 정보

- 회차:
- 이름 / GitHub ID:
- 학습 범위:
- 학습 상태: 완료 / 진행 중

## 📝 배운 내용

이번 범위에서 배운 핵심 내용을 자신의 말로 정리해 주세요.

-
-
-

## 💻 실습 기록

직접 실행해 본 내용과 결과를 적어 주세요.
사용한 프롬프트, 코드, 스크린샷, 결과물 링크 등을 첨부해도 좋습니다.

- 해본 것:
- 실행 결과:
- 알게 된 점:

어떤 문제가 있었고, 어떻게 해결했는지 적어 주세요.
아직 해결하지 못했다면 현재 상황과 시도한 방법을 남겨 주세요.

- 문제:
- 시도한 방법:
- 해결 여부 / 결과:

## 💬 느낀 점과 다음에 해볼 것

-

질문이나 다른 참여자와 공유하고 싶은 내용을 적어 주세요.
없다면 생략해도 됩니다.
```

## 🤝 함께 지켜요

- **강의 내용을 그대로 옮기기보다, 이해한 내용을 자신의 말로 정리합니다.**
- 완벽한 정리보다 꾸준한 학습과 기록을 우선합니다.
- 성공한 결과뿐 아니라 시행착오와 미해결 질문도 환영합니다.
- 다른 사람의 학습 기록에 궁금한 점이나 도움이 될 만한 내용을 댓글로 남깁니다.
- 피드백은 서로를 존중하는 표현으로 작성합니다.
- 강의 원본 자료나 유료 콘텐츠의 무단 공유는 피합니다.
- 코드나 스크린샷을 올리기 전에 **API 키, 토큰, 비밀번호, 개인정보**가 포함되어 있지 않은지 확인합니다.

## ✅ Issue 작성 전 체크리스트

- [ ] 제목을 `[N회차] 이름 - 섹션 X~Y` 형식으로 작성했나요?
- [ ] 실제로 학습한 범위와 진행 상태를 표시했나요?
- [ ] 배운 내용을 자신의 말로 정리했나요?
- [ ] 실습했다면 과정이나 결과를 기록했나요?
- [ ] 민감한 정보가 포함되어 있지 않은지 확인했나요?
